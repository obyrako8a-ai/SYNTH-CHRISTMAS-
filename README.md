Промпт-дизайн:

Разработать прототип веб-синтезатора CHRISTMAS SYNTH на React + Vite с использованием 
Tone.js и Web Audio API. Проект должен быть интерактивным музыкальным инструментом, 
на котором пользователь может самостоятельно создавать и исполнять мелодию, а не просто запускать готовую композицию.

Основная идея: рождественский веб-синтезатор с атмосферным, ярким и немного сказочным звучанием. 
Пользователь должен иметь возможность управлять несколькими инструментами и создавать собственную композицию.

Инструменты: минимум два голоса, в итоговой версии:

VIOLIN
LOW HORN
BELLS
FLUTE
DRUM MACHINE

Для каждого мелодического инструмента нужны:

включение/выключение звука;
выбор пресета/характера звучания;
регулировка скорости;
регулировка громкости;
Для барабанов — отдельная пошаговая сетка с kick,
snare и hi-hat, скоростью и громкостью.

Особенности кода: использовать React-компоненты, состояние для управления инструментами и паттернами, 
Tone.js для синтеза и последовательностей, Web Audio для воспроизведения. Аудио должно запускаться 
только после действия пользователя, чтобы избежать ошибок браузера с AudioContext/autoplay.

Визуальный стиль: минималистичный чёрно-белый интерфейс, простые геометрические элементы и контуры, 
без перегруженной графики и мелкого лишнего текста. Основное внимание — музыкальному функционалу и структуре интерфейса.

Структура интерфейса: первый ряд — VIOLIN и LOW HORN, второй — BELLS и FLUTE, третий, на всю ширину — DRUM MACHINE. 
Название проекта — CHRISTMAS SYNTH.

Код должен быть организован в стандартную структуру Vite/React:
index.html, package.json, package-lock.json, vite.config.js, src/main.jsx, src/App.jsx, src/styles.css.
